Ⅰ. 프로젝트 개요 및 주요 기능Debut 프로젝트

1. 프로젝트 개요

Debut은 개발자의 정보 탐색, 팀 협업, 커리어 기록, 채용 준비와 AI 면접을 하나의 흐름으로 연결하는 커리어 성장 플랫폼이다. 사용자가 활동을 탐색하고 실제 프로젝트 경험을 쌓은 뒤, 이를 취업 자료와 면접 준비에 다시 활용할 수 있도록 지원한다.

1.1 프로젝트 기능 구성

01 인사이트 — 기술 블로그, 대외활동
02 커뮤니티 — 게시판, 댓글·답글, Q&A 채택, 팀 모집·지원
03 워크스페이스 — 팀 공간, 멤버 초대, 칸반, 협업 문서, 화이트보드
04 커리어 관리 — 이력서, 자기소개서, 프로젝트·경력, 포트폴리오
05 채용공고 관리 — 공고 저장, 지원 일정·상태, 자료 연결
06 AI 면접 — 공고·직무 기반 면접, 포트폴리오 디펜스, 결과 리포트
07 마이페이지 — 프로필, 공개 페이지, 작성 내역, 북마크, 알림

2. 오늘의 점검 순서

① 기술 블로그 탐색테크 기업 확인 → 기업 선택 → 기술 콘텐츠 검색 및 조회
② 대외활동 파악프로필 맞춤 추천 → 활동 상세 확인 → 팀 모집 연결
③ 워크스페이스프로젝트 공간 진입 → 협업 기능 확인 → 활동 완료 상태 확인
④ 경험 등록완료된 워크스페이스 기록을 커리어 경험으로 불러오기
⑤ 커리어 문서등록 경험을 활용해 자소서·이력서·포트폴리오 생성
⑥ 모의면접면접 유형 선택 → 자료 연결 → 면접 진행 화면 확인

※ 본 보고서는 사용자 이동 경로와 화면 증적을 중심으로 작성하며, 기능 결과 분석과 개선사항 도출 내용은 별도 정리한다.

Ⅳ. 핵심 사용자 플로우 활동 기록Step 01 · 대외활동 탐색
1

대외활동 목록 화면

사용자는 대외활동 메뉴에서 행사 유형, 검색어와 정렬 기준을 활용해 참여할 활동을 탐색한다.

  • 대외활동 전체 목록과 모집 기간을 확인한다.
  • 활동 카드를 선택하여 상세 화면으로 이동한다.
  • 우측 영역에서 모집 팀과 마감 임박 활동을 함께 확인한다.
6
Ⅳ. 핵심 사용자 플로우 활동 기록Step 02 · 대외활동 상세
2

대외활동 상세 화면

선택한 활동의 일정, 참가 대상, 주요 혜택과 상세 내용을 확인하고 팀원 모집 단계로 이동한다.

  • 활동명, 주최 기관, 일정과 참가 조건을 확인한다.
  • 행사 요약 및 상세 안내를 통해 활동 내용을 파악한다.
  • 팀원 모집하기 기능을 통해 커뮤니티 팀 모집 흐름으로 연결한다.
7
Ⅳ. 핵심 사용자 플로우 활동 기록Step 03 · 팀 모집 및 참여
3

팀 모집 목록 화면

사용자는 활동에 참여할 팀을 확인하거나 새로운 팀을 생성하며, 모집 완료 후 협업 워크스페이스로 이어진다.

  • 프로젝트·스터디·공모전 유형별 팀 모집 글을 확인한다.
  • 모집 인원, 기술 스택, 진행 장소와 모집 상태를 확인한다.
  • 팀 모집 완료 후 생성되는 워크스페이스로 사용자 흐름을 연결한다.
8
Ⅳ. 핵심 사용자 플로우 활동 기록Step 04 · 워크스페이스 선택
4

워크스페이스 목록 화면

팀 모집 또는 기존 프로젝트를 기준으로 진행 중인 협업 공간과 완료된 활동을 확인한다.

  • 프로젝트별 진행 상태와 최근 활동을 확인한다.
  • 점검할 워크스페이스를 선택해 프로젝트 공간으로 진입한다.
9
Ⅳ. 핵심 사용자 플로우 활동 기록Step 05 · 프로젝트 개요
5

워크스페이스 개요 화면

선택한 프로젝트의 기본 정보, 구성원 및 협업 현황을 한 화면에서 확인한다.

  • 프로젝트 목적과 참여 멤버를 확인한다.
  • 보드·문서 등 협업 메뉴로 이동할 수 있다.
10
Ⅳ. 핵심 사용자 플로우 활동 기록Step 06 · 작업 관리
6

워크스페이스 작업 보드

업무를 목록·칸반·타임라인 방식으로 확인하고 담당자와 진행 상태를 관리한다.

  • 업무 단위의 상태와 담당 정보를 확인한다.
  • 표시 방식을 전환해 프로젝트 진행 상황을 파악한다.
11
Ⅳ. 핵심 사용자 플로우 활동 기록Step 07 · 협업 문서
7

워크스페이스 문서 화면

프로젝트 진행 과정에서 필요한 회의록과 기획 문서를 워크스페이스 내부에서 관리한다.

  • 팀 문서를 한 공간에서 조회한다.
  • 새 문서를 생성해 활동 내용을 기록한다.
12
Ⅳ. 핵심 사용자 플로우 활동 기록Step 08 · 활동 완료
8

완료된 워크스페이스 화면

활동이 완료되면 워크스페이스가 읽기 전용 상태로 전환되며, 프로젝트 경험 등록 단계로 연결된다.

  • 완료된 활동의 기록을 조회한다.
  • ‘내 프로젝트로 등록하기’를 통해 커리어 경험 작성으로 이동한다.
13
Ⅳ. 핵심 사용자 플로우 활동 기록Step 09 · 경험 등록
9

프로젝트 경험 등록 화면

완료된 활동을 커리어 프로젝트로 전환하고, 기간·역할·기술·성과를 경험 정보로 정리한다.

  • 워크스페이스 기록을 불러오거나 직접 입력한다.
  • 작성한 프로젝트 경험은 이후 커리어 문서 제작에 활용한다.
14
Ⅳ. 핵심 사용자 플로우 활동 기록Step 10 · 프로젝트 보관함
10

등록 프로젝트 보관함

등록이 완료된 프로젝트 경험을 확인하고 자소서 또는 포트폴리오 작성에 사용할 항목을 선택한다.

  • 저장된 프로젝트의 상태와 핵심 정보를 확인한다.
  • 문서 작성 목적에 따라 프로젝트를 선택한다.
15
Ⅳ. 핵심 사용자 플로우 활동 기록Step 11 · 자기소개서 작성
11

자기소개서 작성 모드

프로젝트 보관함에서 자기소개서 작성 모드로 전환하여 활용할 경험을 선택한다.

  • 자기소개서에 반영할 프로젝트를 선택한다.
  • 선택한 경험을 기반으로 작성 단계로 이어간다.
16
Ⅳ. 핵심 사용자 플로우 활동 기록Step 12 · 자기소개서 관리
12

자기소개서 결과 관리 화면

작성한 자기소개서를 목록으로 관리하고 필요한 항목을 다시 열어 확인한다.

  • 작성 결과의 저장 상태를 확인한다.
  • 지원 목적에 맞는 자기소개서를 선택해 활용한다.
17
Ⅳ. 핵심 사용자 플로우 활동 기록Step 13 · 이력서 관리
13

이력서 보관함

기존 이력서를 확인하고 새 이력서를 생성할 수 있는 관리 화면이다.

  • 작성한 이력서의 목록과 상태를 확인한다.
  • ‘새 이력서 작성’을 선택해 설정 단계로 이동한다.
18
Ⅳ. 핵심 사용자 플로우 활동 기록Step 14 · 이력서 설정
14

새 이력서 작성 설정

지원 직무와 연결할 채용공고를 선택하고 이력서 작성의 기본 정보를 설정한다.

  • 지원 목표와 직무 정보를 입력한다.
  • 저장한 공고를 불러와 문서 작성 기준으로 활용한다.
19
Ⅳ. 핵심 사용자 플로우 활동 기록Step 15 · 포트폴리오 관리
15

포트폴리오 보관함

생성된 포트폴리오를 관리하고 새로운 포트폴리오 제작 흐름을 시작한다.

  • 기존 포트폴리오의 유형과 저장 상태를 확인한다.
  • 새 포트폴리오 만들기를 선택해 프로젝트 선택 단계로 이동한다.
20
Ⅳ. 핵심 사용자 플로우 활동 기록Step 16 · 포트폴리오 작성
16

포트폴리오 작성 모드

프로젝트 보관함을 포트폴리오 작성 모드로 전환하여 활용 가능한 경험을 확인한다.

  • 포트폴리오에 포함할 수 있는 프로젝트를 확인한다.
  • 한 개 이상의 프로젝트를 선택해 다음 단계로 이동한다.
21
Ⅳ. 핵심 사용자 플로우 활동 기록Step 17 · 프로젝트 선택
17

포트폴리오 프로젝트 선택

대표 프로젝트를 선택하고 선택된 항목을 기준으로 포트폴리오 생성 단계에 진입한다.

  • 프로젝트 카드에서 반영할 경험을 선택한다.
  • 선택한 프로젝트로 포트폴리오 생성을 진행한다.
22
Ⅳ. 핵심 사용자 플로우 활동 기록Step 18 · 결과 형식 선택
18

포트폴리오 형식 선택

사용 목적에 따라 슬라이드형 또는 웹형 포트폴리오를 선택한다.

  • 발표·제출 목적에 맞는 출력 형식을 비교한다.
  • 선택한 형식으로 생성 작업을 이어간다.

등록 경험의 문서 활용 흐름

완료된 워크스페이스에서 등록한 프로젝트 경험은 자기소개서, 이력서, 포트폴리오 제작의 공통 자료로 연결된다.

  1. 활동 완료
  2. 경험 등록

  • 기술 블로그 제공 기업을 보여주는 영역과 실제 선택 기능이 하나로 구성되어 있었다.

  • 로고 전광판으로 다양한 테크 기업의 콘텐츠를 제공한다는 의미를 전달한다.

  • 모든 사용자에게 동일한 기준의 목록이 제공되었다.

프로필 기반 대외활동 추천

사용자 프로필에 저장된 기술 스택과 활동의 태그·제목·설명을 비교하여 관련도가 높은 활동을 먼저 노출하도록 변경하였다.

  • 최신순·인기순 선택 대신 ‘프로필 맞춤 추천’ 상태를 표시한다.

  • 프로필과 일치하는 태그를 가진 활동이 목록 상단에 배치된다.

  • 글 작성 시 팀 유형 선택 과정이 필요하였다.
  • 프로젝트 모집이라는 서비스 목적과 다른 유형도 선택할 수 있었다.

불필요한 설정 UI 제거

프로젝트 팀 모집에 필요한 핵심 정보만 작성하도록 모집 유형, 진행 방식, 참고 사항 항목을 화면에서 제거하였다.

  • 모집 유형·진행 방식·참고 사항 UI가 표시되지 않는다.
  • 서버에서는 모집 유형을 프로젝트, 진행 방식을 온라인 기본값으로 저장한다.
  • 작성 안내 문구도 프로젝트 소개 중심으로 변경하였다.

3. 1주차 활동 단계 반영

As-Is 확인 → 개선 방향 설정 → 화면 구현 → 브라우저 검증 → 문서 최신화

기존 사용자 흐름을 확인한 뒤 탐색 방식과 입력 단계를 단순화하였다. 변경 후 기술 블로그 기업 필터, 프로필 추천 결과, 모집 설정 UI 제거 상태를 실제 브라우저에서 확인하였다.

  • 프로필 추천 기준과 활동 노출 결과를 2주차 스프린트 플래닝 자료로 활용한다.
