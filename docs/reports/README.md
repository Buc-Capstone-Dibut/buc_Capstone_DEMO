# 보고서 폴더 규칙

문서를 **날짜(타임라인) 기준**으로 관리한다. **하나의 문서 = 하나의 폴더**이며, 그 폴더 안에 보고서 본문과 필요한 이미지 에셋을 함께 둔다.

## 구조

```
docs/reports/
├── README.md                          ← 이 파일(규칙)
└── YYYY-MM-DD-<주제>/                  ← 문서 1개 = 폴더 1개 (날짜 프리픽스로 시간순 정렬)
    ├── report.html                     ← 본문(A4 인쇄 → PDF 저장 가능)
    └── images/                         ← 이 문서 전용 이미지·로고·캡처
        └── ...
```

## 규칙

- **폴더명**: `YYYY-MM-DD-<주제>` — 날짜가 앞이라 파일 탐색기에서 시간순(타임라인)으로 정렬된다. 필요하면 `2026-W27-...`처럼 주차를 써도 된다.
- **본문**: `report.html` — 브라우저에서 열고 우상단 **"PDF로 저장 / 인쇄(A4)"** 버튼으로 A4 PDF 저장.
- **에셋**: 보고서에 넣을 이미지·로고·캡처는 그 문서 폴더의 `images/`에 넣고, 본문에서 `images/파일명`처럼 **상대경로**로 참조한다(폴더째 옮겨도 안 깨짐). 폴더명을 `assets/`로 하면 `.gitignore` 전역 규칙에 걸려 커밋이 안 되니 `images/`를 쓴다.
- **스타일**: 표지·목차·A4 프린트 CSS는 최신 문서를 복제해 재사용한다. 브랜드 컬러는 부천대학교 골드/오렌지(`#FABF00`·`#F39700`·`#E66C02`).
