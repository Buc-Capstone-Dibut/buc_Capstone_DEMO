# 커리어 공고·자소서 시연 응답

## Why

배포 환경의 외부 AI 지연·실패로 공고 분석과 자소서 작성 시연이 중단된다.

## Outcome

원티드 `https://www.wanted.co.kr/wd/387806` 공고와 본인이 선택한 헬로프렌즈·티니타이거·블레이버스 프로젝트로 공고 등록부터 문항별 자소서 초안·수정·저장까지 진행한다. 기존 분석 표시, 필드 순차 입력, 하이라이트, 생각 중 표시, 답변 타이핑을 유지한다.

## Boundaries

- `CAREER_AI_MODE` 기본값은 `demo`; `live`로 설정하면 기존 AI 경로를 사용한다. 시연 경로는 커리어에서 요청한 지정 공고에만 적용한다.
- 자소서는 로그인한 사용자의 소유 공고와 선택한 프로젝트를 서버에서 확인한다. 다른 사용자 자료나 프로젝트 원문을 공용 시연 데이터에 복사하지 않는다.
- 지정 프로젝트의 등록된 경험을 근거로 문항·단계·선택한 강조 경험·분량에 맞는 준비된 문장을 조합한다. 임의의 질문을 이해하는 범용 AI로 확장하지 않는다.
- 티니타이거는 현재 등록된 API 연동·권한·실시간 데이터 정합성 경험으로 다룬다. 결제·주문 구현, 확인되지 않은 성과나 개인사를 추가하지 않는다.
- 프로젝트 원본, 인증·소유권, 실제 편집·저장·재진입, AI 면접의 공고 분석은 기존 기능을 유지한다. DB 마이그레이션·배포·자동 커밋은 이번 요청 범위에 포함하지 않는다.
- 선택한 공고 ID를 프로젝트 선택 → 자소서 설정 → 저장 → 재진입까지 유지한다. 생성 중 자동 저장을 보류하고 완료된 메시지만 저장하며 화면을 나가면 진행 중 스트림을 취소한다.
- 상시채용 공고를 분석할 때 마감일을 만들지 않는다. 내 공고에서 선택한 경우 날짜 없이도 자소서 설정을 진행할 수 있다.

## Done when

- 지정 공고의 주요 필드가 외부 AI 없이 기존 순차 입력 효과로 채워진다.
- 자소서 첫 안내, 방향 합의, 초안, 수정, 분량 조정, 최종 확인의 텍스트 스트림과 내부 상태 프로토콜이 정상 동작한다.
- 선택하지 않은 프로젝트가 답변에 포함되지 않고 문항 분량 제한을 지킨다.
- 내부 프로토콜이 타이핑 중 화면에 노출되지 않으며 스트림 취소 시 대기 작업을 정리한다.
- 실제 초안 적용·저장·다시 열기와 시연 범위 외 기존 경로를 검증한다.
