# 면접 콘솔 모범답변

## Why

연습 중 현재 질문에 어떻게 답할지 짧은 예시를 확인하고 싶다. 기존 콘솔 출력은 문장 틀이라 실제 질문과 지원 자료를 충분히 반영하지 못한다.

## Outcome

- 면접 화면에서 `interviewCoach.start()`로 현재 질문과 이후 질문의 모범답변을 콘솔에 출력한다.
- `interviewCoach.answer()`는 현재 질문만 요청하고, `interviewCoach.stop()`은 자동 출력을 중단한다.
- 공고 면접은 공고·선택한 이력서·연결 자료, 직무 면접은 선택 직무, 디펜스는 저장된 GitHub 분석을 반영한다.

## Boundaries

- 답변은 한국어 2~4문장, 최대 360자다. 자료에 없는 개인 경험·역할·성과를 만들지 않는다.
- 세션과 포트폴리오는 본인 소유 자료만 조회한다. 답변 생성은 면접 대화·평가 기록에 저장하지 않는다.
- 명령 실행 전에는 생성하지 않는다. 같은 질문의 중복 요청을 합치고, 질문 변경·중단·페이지 이탈 시 이전 요청을 취소한다.

## Done when

- 세 유형의 자료가 각각 프롬프트에 포함되고, 긴 응답은 길이 제한을 지킨다.
- 로그인·소유권 검사와 콘솔 명령의 자동 출력·중복 요청·취소 동작을 검증한다.
- 실제 생성 모델로 짧은 모범답변이 반환되는지 확인한다.
