# 시연 면접 질문 전환과 음성 안정화

## Why

시연 질문은 고정인데 세션별 Gemini Live 낭독·선생성 실패가 전송 후 대기를 만든다. 첫 질문의 맞장구가 늘어지듯 들리는 음성도 매번 다시 생성돼 발음이 일정하지 않다.

## Outcome

- 검증해 미리 생성한 시연 오프닝·질문·종료 음성을 배포에 포함해 즉시 재사용한다.
- 첫 질문의 짧은 맞장구를 또렷하게 전달한다.
- 시연 전송에서 필요 없는 중간 상태 DB 쓰기와 STT 종료 대기를 줄인다.

## Boundaries

- 질문 문장, 질문 순서, 일반 AI 면접 생성 방식은 유지한다.
- 음성의 원문 해시가 대본과 일치할 때만 사용한다. 누락·손상·대본 변경 시 기존 생성 경로로 폴백한다.
- 전사 품질 보정은 다음 질문 음성 전달을 기다리게 하지 않는다.

## Done when

- 번들 음성이 있는 시연 세션에서 질문 음성을 위해 Gemini 호출이나 선생성 완료를 기다리지 않는다.
- 시연 질문 순서·재시도·재연결·종료 회귀 검사가 통과한다.
- 첫 질문 음성을 실제 생성 원본과 비교하고 짧은 맞장구가 자연스러운지 사용자가 확인할 수 있다.
