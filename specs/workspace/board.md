# 워크스페이스 보드

## Why

워크스페이스의 작업은 여러 보드로 분리하지 않는다. 하나의 보드 안에서 상태·담당자·우선순위·태그를 보기 기준으로 사용하면 작업을 누락하거나 보드 간 이동을 관리할 필요 없이 같은 업무 맥락을 유지할 수 있다.

## Outcome

- 사용자는 작업 메뉴에 들어가면 목록 화면을 거치지 않고 단일 보드로 바로 진입한다.
- 같은 작업을 목록·칸반·타임라인으로 전환한다.
- 타임라인은 일간·주간·월간 축척으로 작업 기간을 확인한다.
- 타임라인은 전체·기간 설정·기간 미정 작업을 즉시 전환해 확인한다.
- 목록·칸반·타임라인은 상태·담당자·우선순위·태그 기준으로 같은 작업을 그룹화한다.
- 검색·필터·정렬은 목록과 칸반에 일관되게 적용된다.
- 작업에는 날짜만 사용하는 시작일과 종료일을 각각 지정한다.
- 작업 상세의 단일 달력에서 시작일과 종료일을 차례로 선택하고 확인한 뒤 적용한다.
- 상태 상위 축과 세부 상태의 표시 순서를 각각 조정한다.

## Boundaries

- 내비게이션 이름은 “작업”, 작업 화면 이름은 “보드”로 한다.
- 워크스페이스당 보드는 하나이며 생성·보관·이동 기능을 두지 않는다.
- 목표·에픽·스프린트 같은 별도 상하 구조는 추가하지 않는다.
- 상태·우선순위·태그·멤버는 워크스페이스 공용 설정이다.
- 상태 관리에서 세부 상태의 색을 바꾸면 목록·칸반·타임라인의 해당 상태 표현에 함께 반영한다.
- 태그는 그룹 기준이자 메타데이터이며 보드나 목표의 대체 식별자로 사용하지 않는다.
- 다중 보드에 나뉘었던 기존 태스크는 삭제하지 않고 단일 보드에 합친다.

## Done when

- 작업 메뉴 진입 즉시 단일 보드와 전체 태스크가 표시된다.
- 목록과 칸반에서 네 가지 그룹 기준과 공통 검색·필터가 실제 표시 결과를 바꾼다.
- 타임라인에서 일간·주간·월간 축척을 전환하고 오늘 기준선과 작업 기간을 확인할 수 있다.
- 타임라인의 그룹을 접거나 펼칠 수 있고, 보기 기준을 바꾸면 왼쪽 작업 트리도 같은 기준으로 다시 묶인다.
- 타임라인 그룹은 채워진 작업 행이 아니라 얇은 실선 섹션으로 구분한다.
- 타임라인의 상태 점·기간 막대·섹션 선은 저채도 파스텔 팔레트로 통일한다.
- 타임라인의 Task 점과 기간 막대는 상태 색을 유지하고, 섹션 선·꺾쇠·라벨은 현재 그룹 기준의 상태·우선순위·태그 색 또는 담당자 프로필을 사용한다.
- 타임라인 기간 막대는 가로 스크롤 시 고정된 작업 패널 아래로 지나간다.
- 타임라인 왼쪽 작업 패널은 경계를 끌어 너비를 조절하고 더블클릭해 기본 너비로 되돌린다.
- 기간이 없는 작업도 타임라인의 왼쪽 작업 목록에서 누락되지 않으며 `미정` 필터로 모아볼 수 있다.
- 타임라인의 작업명이나 기간 막대를 누르면 같은 작업 상세 패널이 열린다.
- 작업 상세 패널은 짧은 전환으로 즉시 열리며, 기간 버튼을 누르면 한 달력에서 선택값을 확인한 뒤 명시적으로 적용한다.
- 타임라인 기간 막대 전체를 끌어 시작일·종료일을 함께 옮기고, 양 끝을 끌어 각 날짜를 조정한다.
- 기간 편집은 화면에 즉시 반영한 뒤 기존 저장 큐에서 순서대로 처리하며, 저장 실패 시 확정 전 값으로 되돌린다.
- 작업의 시작일·종료일을 저장하고 다시 열어도 같은 날짜가 표시되며 시작일이 종료일보다 늦은 값은 저장되지 않는다.
- 존재하지 않는 태그 ID를 작업에 저장할 수 없고, 태그 삭제 시 작업의 참조도 함께 제거된다.
- 상태 순서를 바꾸거나 칸반 카드를 이동해도 작업이 사라지거나 중복 표시되지 않는다.

## Next

- 보드 상단에 일정 위험, 담당 현황, 최근 활동을 필요한 만큼만 요약한다.
- 기간 미정 작업을 타임라인의 원하는 날짜에 놓아 일정을 시작한다.
- 여러 작업을 선택해 기간을 함께 이동하거나 늘리는 일괄 편집을 제공한다.
- 사용자가 마지막으로 선택한 레이아웃과 보기 설정을 저장한다.
